# Archive

`prd-review/` holds the 289 review records (PRDR-041 to PRDR-337) that shaped Detent up to version 3.2. Code comments, test names and the PRD cite them by id, such as `PRDR-286`, so they stay here for anyone who wants the reasoning behind a rule.

Detent no longer uses them. Since 13 October 2026, a bug or an idea is a [GitHub issue](https://github.com/djazairdev/detent/issues), and a change cites the issue it fixes (`#123`). There's no separate record to file and no approval step: see [CONTRIBUTING](../CONTRIBUTING.md).
